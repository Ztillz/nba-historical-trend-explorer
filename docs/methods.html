A guide to asking useful questions, reading results, and reproducing the analysis.

Start with a question

Use Historical queries to find teams matching a pattern: for example, losing the rebound battle in at least 8 of the first 10 games. Add positive point differential to ask how context changes eventual outcomes. Full-season results include the observation games.

Use Research to ask what carries forward. Observe first 10/20/30 games and measure wins or point differential strictly afterward. Select a statistic, inspect dots and team evidence, and check whether it improves a simple benchmark. Copy the experiment link to revisit its settings.

Read the evidence

Spearman ρ compares ranks. Near +1 means higher early values generally accompany higher later results; near −1 means the reverse. Zero means little monotonic association. Lower turnover differential is usually better, so negative correlation can be sensible. Constant samples show an unavailable result.

The 95% interval resamples whole seasons, preserving within-season shared-game relationships. Require five seasons; defaults are 500 draws and seed 471. Repeated franchises across years remain a limitation. The interval is an approximate exploratory estimate.

Each dot is one team-season. Click it or a team in the table to inspect dates. Search/sorting affect the table; CSV includes the entire complete selected-statistic sample. Analysis JSON records filters, assumptions, and benchmark predictions.

Check incremental usefulness

Strong correlation may reflect information already in early wins and point differential. Three linear benchmarks compare an earlier-season average, early record plus point differential, and the same baseline with the selected statistic added.

Default: fit before 2016–17, evaluate 2016–17 onward. Models share complete cases; scaling uses earlier rows only. MAE measures average error size; RMSE emphasizes large errors. Lower is better. Win-percentage errors use percentage points.

These are retrospective comparisons on seasons already examined. Changing the split or browsing statistics does not create an untouched test. Small error reductions need further validation. A tiny fixed slope penalty stabilizes the fit; linear predictions are not calibrated probabilities.

Know which teams are included

The snapshot contains 98,236 regular-season team-game rows and 1,223 team-seasons, 1983–84 through 2025–26. Basic gaps occur in the first two seasons. Advanced season ratings start in 1996–97.

Observation windows require consecutive games and every needed statistic. Missing values stay unknown. Historical queries require all condition metrics, including OR queries; their baseline includes only usable windows. Rolling queries count team-seasons once, with matching windows separately counted.

Research requires complete early record and point differential and complete future wins/point differential. Extra statistics have individual complete samples. Fixed future horizons require all requested games. Shortened seasons use actual game numbers. Remaining season ends at the last stored game; unfinished seasons must be excluded before a future data refresh.

Point differential is points per game; no game-level possessions are available, so it is not called net rating. Opponents, injuries, rosters, and era effects are not explicitly adjusted for. Decade splits aid inspection without removing those factors.

Reproduce a result

Clone the repository, install requirements.txt, run python run_research.py. It reads the committed snapshot without calling NBA endpoints, regenerating features, findings, and CSV. Serve with python -m http.server 8000 --directory docs --bind 127.0.0.1.

The generated report adds rebounds, assists, and turnovers together; the interactive benchmark adds the selected signal individually. Both use the early-record/point-differential baseline.
